About

A bit more about how I got here.

Background, focus, and how I approach client work.

I'm a freelance web developer based in Pakistan. I build with React and Next.js, and I care about structure as much as visuals: code that's easy to hand off, extend, or come back to months later without needing a rewrite.

Alongside the build work, I have hands-on experience setting up analytics and SEO tooling, including GA4, Google Tag Manager, schema markup and Core Web Vitals, so the sites I make can be measured and found, not just looked at.

Outside client work, I'm developing skills in game development. I'm building a fantasy MMORPG solo in Godot, which has taught me to break a big system into small, manageable pieces, a habit that carries straight into how I structure a codebase like this one.
